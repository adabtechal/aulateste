## Story
> Como cliente que recebeu um link de agendamento via WhatsApp,
> Quero acessar uma pagina publica com calendario e formulario para escolher data, horario e preencher meus dados,
> Para que eu possa agendar um atendimento de forma rapida e autonoma pelo celular.

- [ ] AC1: Pagina publica acessivel via `/booking/:tenantSlug` sem necessidade de login/autenticacao

## Dev Notes

### Architecture Reference

**Rota Publica Pattern** [Source: client/src/App.jsx]
- Rotas publicas ficam FORA do `<ProtectedRoute>` wrapper
- Existentes: `/login`, `/reset-password`
- Nova rota `/booking/:tenantSlug` segue mesmo pattern

**Express Route Pattern** [Source: server/src/routes/webhook.js]
- Endpoints sem auth nao usam middleware `requireAuth`
- Usar `supabase` com service_role para operacoes publicas (bypass RLS)

**API Client para Pagina Publica** [Nota Importante]
- A pagina publica NAO deve usar `client/src/services/api.js` (tem interceptor de auth)
- Usar axios direto com baseURL `/api` para chamadas publicas
- Alternativa: criar helper separado `client/src/services/publicApi.js`

**Paginacao Pattern** [Source: server/src/routes/leads.js]
```javascript
const { page = 1, limit = 20, date, status } = req.query;
const offset = (page - 1) * limit;
// Retorna: { data, pagination: { page, limit, total, totalPages } }
```

**Sidebar Pattern** [Source: client/src/App.jsx]

```javascript
{ to: '/scheduling-config', icon: Calendar, label: 'Config Agenda' }

```

### Geracao de Slots de 30min

Para gerar slots de horario a partir das faixas de disponibilidade:
```javascript
function generateTimeSlots(startTime, endTime, intervalMinutes = 30) {
  const slots = [];
  let current = parseTime(startTime); // ex: "09:00" → { h: 9, m: 0 }
  const end = parseTime(endTime);
  while (current < end) {
    slots.push(formatTime(current)); // ex: "09:00"
    current += intervalMinutes;
  }
  return slots;
}
```

### Race Condition no Booking

Ao confirmar, verificar se slot ainda esta livre:
```sql
SELECT count(*) FROM bookings
WHERE tenant_id = $1 AND booking_date = $2 AND booking_time = $3
AND status = 'confirmed'
```
Se count > 0, retornar erro 409 Conflict.

### Formato Telefone BR
- Celular: (XX) XXXXX-XXXX (11 digitos)
- Fixo: (XX) XXXX-XXXX (10 digitos)
- Regex: `/^\(\d{2}\) \d{4,5}-\d{4}$/`
- Armazenar apenas digitos no banco: `/^\d{10,11}$/`
