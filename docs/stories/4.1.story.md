## Dev Notes

### Architecture Reference

**Migration Pattern** [Source: supabase/migrations/20260402153000_create_tenant_bot_configs.sql]
- Usar `gen_random_uuid()` para PKs
- FK com `ON DELETE CASCADE` para tenant_id
- Trigger `set_{table}_updated_at` com funcao PL/pgSQL
- Indexes por tenant_id obrigatorios

**Realtime Pattern** [Source: supabase/migrations/20260416120000_enable_realtime_message_log.sql]
- Idempotente com `DO $$ BEGIN ... EXCEPTION WHEN ... END $$`
- `ALTER PUBLICATION supabase_realtime ADD TABLE public.{table}`
- `ALTER TABLE REPLICA IDENTITY FULL`

**Route Pattern** [Source: server/src/routes/autoMessages.js]
- Router com requireAuth middleware
- Role check para operacoes de escrita
- Supabase queries com `.select()`, `.eq()`, `.order()`
- Paginacao: `{ page = 1, limit = 20 }` com offset

**Frontend Pattern** [Source: client/src/App.jsx]
- configLinks array: `{ to, icon, label }` — visivel apenas para superadmin/tenant_admin
- Import Lucide icon: `import { Calendar } from 'lucide-react'`

**API Client Pattern** [Source: client/src/services/api.js]
- Todos os metodos retornam `.then(r => r.data)`
- Axios instance com baseURL `/api` e interceptor de auth

### Modelo de Dados Completo

```sql
-- scheduling_availability
CREATE TABLE IF NOT EXISTS public.scheduling_availability (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  day_of_week integer NOT NULL CHECK (day_of_week BETWEEN 0 AND 6),
  start_time time NOT NULL,
  end_time time NOT NULL,
  is_active boolean NOT NULL DEFAULT true,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now(),
  CONSTRAINT valid_time_range CHECK (start_time < end_time)
);

-- bookings
CREATE TABLE IF NOT EXISTS public.bookings (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  tenant_id uuid NOT NULL REFERENCES public.tenants(id) ON DELETE CASCADE,
  lead_id uuid REFERENCES public.leads(id) ON DELETE SET NULL,
  client_name text NOT NULL,
  client_phone text NOT NULL,
  service_interest text NOT NULL,
  booking_date date NOT NULL,
  booking_time time NOT NULL,
  status text NOT NULL DEFAULT 'confirmed'
    CHECK (status IN ('confirmed', 'cancelled', 'completed', 'no_show')),
  confirmation_sent boolean NOT NULL DEFAULT false,
  confirmation_sent_at timestamptz,
  notes text,
  created_at timestamptz DEFAULT now(),
  updated_at timestamptz DEFAULT now()
);
```
